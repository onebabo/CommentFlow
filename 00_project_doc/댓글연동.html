CommentFlow 댓글 연동 사용법

즐겨찾기 작품의 회차 감상 댓글을 초안 → 규정 검사 → 복사 → 직접 등록하는 도우미

1. 개요

회차 직접 읽기→ 감상 메모로 draft→ 규정 검사→ copy : 클립보드 + 페이지 열기→ 붙여넣고 직접 등록→ y 입력 → 등록완료 기록
사이트 등록 버튼은 항상 사용자가 직접 누릅니다. 자동 등록·예약 등록 기능은 없습니다. 직접 읽고 느낀 감상만 메모로 입력하세요.
  • 즐겨찾기 작품(book_web_Crawler의 book_work_list, used='Y')에만 초안을 만들 수 있습니다.
  • 의미 없는 인사말 댓글, 유료 회차·절차 관련 불평 단어가 들어간 댓글은 저장되지 않습니다.
  • 초안·등록 기록은 book_comment 테이블에 남습니다.

2. 설치 / 설정

① Python 3.10 이상 설치

python.org에서 설치 (설치 시 Add python.exe to PATH 체크). Microsoft Store 바로가기(WindowsApps\python.exe)만 있으면 실행되지 않습니다.

python --version

② 패키지 설치

cd D:\workspaces\github\onebabo\CommentFlow
pip install -r requirements.txt

③ DB 설정 파일

config.example.ini를 config.ini로 복사하고 비밀번호를 채웁니다. config.ini는 git에 올라가지 않습니다.

[mysql]
host = book.db.baeoom.com
port = 3306
user = book_admin
password = 실제_비밀번호
database = onebabo_book
charset = utf8mb4

3. 사용 순서

① 즐겨찾기 작품 확인

python commentflow.py works

목록에 댓글 달 작품의 book_id(URL의 /novel/59094/…)가 있어야 합니다.

② 회차를 읽고 감상 메모로 초안 작성

python commentflow.py draft https://toki35.com/novel/59094/6063116 --memo "제목이 세계재벌이라 부를 쌓는 이야기를 기대했는데 전쟁(분쟁) 파트가 너무 많아서 약간 아쉬움"

초안 후보 3개와 규정 검사 결과가 표시됩니다.

작품: 초전도체 - 세계재벌

  1) 제목이 세계재벌이라 … 약간 아쉬움.
  2) 제목이 세계재벌이라 … 약간 아쉬움. 다음 화도 기대하겠습니다.
  3) 제목이 세계재벌이라 … 약간 아쉬움. 앞으로 어떻게 전개될지 궁금하네요.

번호 선택 / e: 직접 입력 / 그 외: 취소
> 2
초안 #1 저장. 등록하려면: python commentflow.py copy 1

③ 복사 + 페이지 열기 → 직접 등록

python commentflow.py copy 1
  1. 댓글이 클립보드에 복사되고 회차 페이지가 브라우저에 열립니다.
  2. 댓글 입력창에 Ctrl+V로 붙여넣고 직접 등록합니다.
  3. 터미널로 돌아와 y 입력 → 등록완료(P)로 기록됩니다. 아직이면 Enter (복사함 C 상태로 남음).

④ 기록 확인

python commentflow.py list            # 최근 20건
python commentflow.py list --status D # 아직 등록 안 한 초안

5. 댓글 규정 검사 (rules.py)

사이트 댓글 규정에 맞춰 아래 경우 저장을 막습니다.

검사기준
의미 없는 댓글"감사합니다", "잘봤어요", "수고하셨습니다" 등 인사말과 ㅋㅋ/ㅎㅎ·기호를 뺀 감상이 15자 미만
유료 회차 불평"유료", "결제", "포인트", "크롤링", "아류", "인증", "잠금", "절차", "왜 막", "못 보게" 포함
주의(저장은 됨)500자 초과, 같은 내용으로 이미 등록한 기록 있음
> python commentflow.py check "잘봤어요 감사합니다"
    [불가] 감상 내용이 너무 짧습니다 (인사말 제외 0자, 최소 15자).
규정 위반

통과 예 제목이 세계재벌이라 부를 쌓는 이야기를 기대했는데 전쟁 파트가 많아서 조금 아쉽네요.
위반 예 잘봤습니다 ㅎㅎ / 유료 회차 왜 막아놨나요

금지 단어·최소 길이는 rules.py 맨 위 FILLER_PHRASES, COMPLAINT_KEYWORDS, MIN_MEANINGFUL_CHARS에서 수정합니다.

6. DB 구조

DB: book.db.baeoom.com / onebabo_book (book_web_Crawler와 공용)

book_work_list (크롤러 관리, 읽기만 함)

book_id, title, sort_no, used, last_episode_no 를 사용합니다.

book_comment (CommentFlow, 접속 시 자동 생성)

컬럼설명
comment_seqPK (초안 번호)
book_id소설 아이디 (book_work_list.book_id, FK 없음)
episode_url댓글 달 회차 URL
memo입력한 감상 메모
body최종 댓글 내용
statusD 초안 / C 복사함 / P 등록완료
posted_at등록 완료 일시
created_at, updated_at생성 / 수정 일시

생성 SQL: comment_sql/00_comment_테이블생성.sql. 크롤러가 즐겨찾기 동기화 때 book_work_list 행을 삭제하므로 FK를 걸지 않았고, 해제된 작품의 기록은 목록에 "(즐겨찾기 해제됨)"으로 표시됩니다.

7. 문제 해결

증상조치
DB 설정 파일을 찾을 수 없습니다프로젝트 루트에 config.ini 생성 (2-③)
즐겨찾기(book_work_list)에 없는 작품입니다사이트 즐겨찾기 추가 후 book_web_Crawler로 즐겨찾기 목록 동기화, 또는 used='Y' 확인
회차 URL 형식이 아닙니다https://도메인/novel/{book_id}/{회차id} 형식인지 확인
DB 접속 실패 / 시간 초과book.db.baeoom.com:3306 접속 가능 여부, 비밀번호 확인
python 실행 시 Store가 열림python.org 설치 후 PATH 등록, 새 터미널에서 다시 실행
클립보드 복사 오류 (tkinter)Python 설치 시 tcl/tk and IDLE 옵션 포함해서 설치
