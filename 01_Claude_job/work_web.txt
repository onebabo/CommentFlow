book_web 에 "추천 댓글" 페이지를 추가해줘.

※ 먼저 확인: book_web 브랜치 comment-list (커밋 2dfbc31)에 이 기능 초안이 이미 있다.
   그 브랜치를 기준으로 아래 요구사항과 비교·검토해서 빠진 부분을 보완하고, 빌드(npm run build)까지 확인해줘.
   (master 에는 아직 병합 안 됨. master 에 직접 병합하지 말고 브랜치로 작업)

1. 상단 메뉴
   - SiteHeader 의 "onebabo book" 로고 우측에 작은 아이콘 버튼(댓글 말풍선 아이콘) 추가
   - 링크: /comment_list  (https://onebabobook.baeoom.com/comment_list)
   - 기존 로그아웃 점·성인 카테고리 아이콘처럼 작고 눈에 덜 띄게

2. /comment_list 페이지
   - 카테고리 탭: 소설 / 웹툰 / 만화  (기본 소설, ?kind=novel|toon|manhwa)
   - 목록: 추천 댓글 저장 내역 최신순, 20개씩 페이징 (기존 Pagination 컴포넌트 사용)
   - 썸네일 없이 제목만 나열식 리스트
       1줄: [상태] 작품 제목 · N화 회차제목 · 생성일
            (제목 클릭 → 이 사이트 회차 보기 /book_view/{id}/{code}, /toon_view/{id}/{no}, /manhwa_view/{id}/{no})
       2줄: 추천 댓글 내용 (textarea, 수정 → [저장])
       접기: 회차 요약(summary)
   - 버튼: [저장] [연동] [등록완료/취소] [삭제]
   - 상단에 [댓글 생성] 버튼

3. [댓글 생성] 버튼
   - 서버에서 CommentFlow 파이썬 실행 (기존 src/lib/book-register.ts 의 spawn 방식 참고)
       cwd    : COMMENTFLOW_DIR (기본 D:\workspaces\github\onebabo\CommentFlow)
       python : COMMENTFLOW_PYTHON → <COMMENTFLOW_DIR>\.venv\Scripts\python.exe → python
       명령   : python commentflow.py recommend --kind <현재 탭> --count 20
   - 파이썬이 하는 일: 추천 댓글이 없는 보유 작품 20개 랜덤 선정 → 회차 내용 분석(Claude API) → 규정 통과 댓글만 DB 저장
   - 한 번에 하나만 실행 (실행 중이면 버튼 비활성 + "생성 중…" + 로그 마지막 줄 표시)
   - 작품마다 바로 저장되므로 실행 중에는 몇 초마다 목록 새로고침
   - 로그 파일: COMMENTFLOW_LOG_DIR (기본 <COMMENTFLOW_DIR>\_web_log), 타임아웃 COMMENTFLOW_TIMEOUT_MIN (기본 60)
   - .env.example 에 위 환경변수 설명 추가

4. [연동] 버튼 — 원글 댓글 폼으로 내용 전달
   - 댓글 내용을 클립보드에 복사 + 원글 회차 페이지(source_url)를 새 탭으로 열기
       예) https://onebabobook.baeoom.com/book_view/59094/6063116  →  https://toki35.com/novel/59094/6063116
   - 원글 댓글 입력창에 붙여넣고 "등록" 은 사용자가 직접 누른다
   - 상태를 C(연동함)로 변경, 등록 후 [등록완료] 누르면 P
   - ※ 원글 사이트에 자동으로 댓글을 등록하거나 예약·반복 등록하는 기능은 만들지 말 것

5. 댓글 규정 (저장·연동 전에 반드시 검사, 위반이면 저장/연동 막고 사유 표시)
   ⚠ 작품 감상평이 아닌 의미 없는 댓글(예: "감사합니다", "잘봤어요" 등) 작성 시 댓글 삭제 및 영구 차단됩니다.
   ⚠ 일부 유료 회차는 크롤링해가는 아류사이트들로 인해 어쩔 수 없이 도입된 절차이니 양해부탁드리며, 관련 불평 댓글 작성 시 악용자로 간주하여 영구 차단합니다.
   - 검사 기준은 CommentFlow/rules.py 와 동일하게 (TS 로 옮겨 클라이언트·서버 공용)
       · 인사말("감사합니다","잘봤어요","수고하셨습니다","재밌어요" 등)·ㅋㅋ/기호 제외 감상 15자 미만 → 불가
       · "유료","결제","포인트","크롤링","아류","인증","잠금","절차","왜 막","못 보게" 포함 → 불가
       · 500자 초과 → 주의

6. DB — book_comment_recommend
   (CommentFlow 가 첫 실행 때 자동 생성, 정의: CommentFlow/comment_sql/01_comment_recommend_테이블생성.sql)
   - 테이블이 아직 없으면(errno 1146) 에러 대신 빈 목록 표시
   - 주요 컬럼
       rec_seq PK / kind (novel,toon,manhwa) / work_id / episode_code VARCHAR(웹툰은 'nv-847903-1' 형식) / episode_no
       work_title / episode_title / source_url (원글 회차 URL) / summary (회차 요약) / body (추천 댓글)
       status (R:추천, S:수정저장, C:연동함, P:등록완료) / linked_at / posted_at / created_at
   - 저장: body 수정 시 status R→S (C/P 는 유지)
   - 원글 도메인이 바뀌었을 수 있음(toki34→toki35) → 링크 만들 때 현재 도메인 기준으로 보정

7. 마무리
   - npm run lint / npm run build 통과 확인
   - work_ai/YYYY-MM-DD_NNN.html 작업 기록 남기기 (프로젝트 규칙)
   - 커밋 후 브랜치 push (master 병합은 내가 확인 후 직접)
